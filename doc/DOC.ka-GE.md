## დაწყება

ჩამოტვირთეთ თქვენი Windows-ისთვის შესაფერისი zip
[გამოშვებების გვერდიდან](https://github.com/varmtlys/repicotorrent/releases/latest):
`x64` 64-ბიტიანი Windows-ისთვის, `arm64` ARM-ზე მომუშავე Windows-ისთვის, `x86`
32-ბიტიანი Windows-ისთვის. გახსენით ის ნებისმიერ საქაღალდეში, სადაც ჩაწერის
უფლება გაქვთ, და გაუშვით `RePicoTorrent.exe`. არაფერი ინსტალირდება:
პარამეტრები, ტორენტების სია და ჟურნალები exe-ის გვერდით ინახება, ამიტომ
საქაღალდის გადატანა ან USB დისკზე კოპირება შეიძლება.

თითოეული საქაღალდე პროგრამის ცალკე ასლია. სხვადასხვა საქაღალდის ორ ასლს
ერთდროულად მუშაობა შეუძლია, თუ ისინი სხვადასხვა პორტს იყენებენ.


## მთავარი ფანჯარა

![მთავარი ფანჯარა](images/en-US/main.png)

ზემოთ ტორენტების სიაა. ნებისმიერი სვეტი სათაურზე დაწკაპუნებით ლაგდება;
სათაურებზე მარჯვენა დაწკაპუნება სვეტებს აჩენს ან მალავს.

- **პროგრესი** და **Done**: სასურველი მონაცემების რა ნაწილია
  ჩამოტვირთული.
- **დარჩენილი**, **ჩამოტვირთვა**, **ატვირთვა**: დარჩენილი დრო, ჩამოტვირთვისა და
  ატვირთვის სიჩქარე.
- **Availability**: რამდენი სრული ასლი აქვთ ერთად დაკავშირებულ
  პირებს.
- **Seeds**, **პირები**, **Leechers**: დაკავშირებულები, ფრჩხილებში კი
  მთელი ჯგუფის რაოდენობა ტრეკერების მონაცემებით.

ქვემოთ არჩეული ტორენტის დეტალებია:

- **მიმოხილვა**: სახელი, ჰეშები (v1 და v2), ზომა, შენახვის საქაღალდე,
  კომენტარი და ჯამები. კომენტარის ბმულები ბრაუზერში იხსნება. ზედა ზოლი
  ნაწილებს აჩვენებს: ყოველი ჩამოტვირთული ნაწილი ტორენტში თავის ადგილზეა
  შეღებილი. ნაწილები თანმიმდევრობით არ მოდის (ჯერ ყველაზე იშვიათები),
  ამიტომ დაუსრულებელ ტორენტს ხარვეზები აქვს.
- **ფაილები**: ფაილები და საქაღალდეები პროგრესით. მარჯვენა დაწკაპუნებით
  შეგიძლიათ პრიორიტეტის მითითება ან ფაილის გამოტოვება; ორმაგი დაწკაპუნება
  ჩამოტვირთულ ფაილს ხსნის.
- **პირები**: დაკავშირებული პირები ქვეყნით, კლიენტით, სიჩქარეებით და
  სიტყვებით დაწერილი კავშირის ალმებით.
- **ტრეკერები**: ტრეკერის მდგომარეობა, მის მიერ მოწოდებული სიდერები და
  ლიჩერები და შემდეგი განცხადება. მარჯვენა დაწკაპუნებით დამატება, წაშლა
  ან ხელახლა განცხადება.

მდგომარეობის ზოლი აჩვენებს ტორენტების რაოდენობას, DHT კვანძებს, მიმდინარე
სიჩქარეებს, ჩართულია თუ არა IP ფილტრი და რამდენი გადაიცა ამ სესიაში.
**ხედი** მენიუ მალავს ან აჩენს დეტალების პანელს, მდგომარეობის ზოლს
და კონსოლს.


## ტორენტების დამატება

- **ფაილი > ტორენტის დამატება** (Ctrl+O): აირჩიეთ ერთი ან რამდენიმე
  `.torrent` ფაილი.
- **ფაილი > მაგნიტური ბმულ(ებ)ის დამატება** (Ctrl+U): ჩასვით magnet
  ბმულები, თითო სტრიქონზე ერთი.
- გახსენით `.torrent` ფაილი ან magnet ბმული `RePicoTorrent.exe`-ით; თუ ამ
  საქაღალდის პროგრამა უკვე მუშაობს, ტორენტი მას გადაეცემა.

დამატებამდე შეგიძლიათ აირჩიოთ საქაღალდე, საჭირო ფაილები და იარლიყი.
ტორენტების ნაგულისხმევი პარამეტრებით მაშინვე დასამატებლად პარამეტრებში
ჩართეთ **Skip 'Add torrent' dialog**.


## ტორენტების მართვა

დააწკაპუნეთ მარჯვენა ღილაკით ერთ ან რამდენიმე ტორენტზე:

- **გაგრძელება**, **გაგრძელება (იძულებით)** (რიგს უგულებელყოფს), **შეჩერება**.
- **Force reannounce**, **Force recheck** (დისკზე მონაცემებს ამოწმებს).
- **თანმიმდევრული ჩამოტვირთვები**: ნაწილები თანმიმდევრობით ჩამოიტვირთება, რაც
  მოსახერხებელია ვიდეოს ყურებისთვის ჩამოტვირთვისას.
- **Label**: იარლიყის მინიჭება.
- **Export**: magnet ბმული ან `.torrent` ფაილი.
- **გადაადგილება**: მონაცემების სხვა საქაღალდეში გადატანა.
- **ამოღება**: ტორენტის წაშლა (Del) ან ტორენტის წაშლა ფაილებთან ერთად
  (Shift+Del).
- **რიგში ჩადგომა**: ზემოთ ან ქვემოთ ჩამოტვირთვის რიგში.
- **ჰეშ-ინფოს კოპირება**, **გახსნა Explorer-ში**.


## იარლიყები

იარლიყები ტორენტებს აჯგუფებს. ისინი იქმნება
**პარამეტრები > Labels**-ში:

- **Color**: იარლიყის ფერი; თუ **საერთო**-ში ჩართულია
  **Use label color as background in torrent list**, სტრიქონები ამ ფერით
  იღებება.
- **შენახვის ბილიკი**: ამ იარლიყით დამატებული ტორენტები აქ ინახება.
- **Apply filter**: რეგულარული გამოსახულება; ახალი ტორენტი, რომლის
  სახელიც მას ემთხვევა, ამ იარლიყს ავტომატურად იღებს. მაგალითი:
  `ubuntu|debian|fedora`.

**ხედი > Labels** მხოლოდ ერთი იარლიყის ტორენტებს აჩვენებს.


## ფილტრები და კონსოლი

**ხედი > Filter**-ში შენახული ფილტრებია, მაგალითად, ახლა
ჩამოტვირთვადი ტორენტები. **ხედი > Console** სიის ქვემოთ
სტრიქონს ხსნის: ჩაწერეთ მოთხოვნა და დააჭირეთ Enter-ს, რომ მხოლოდ შესაბამისი
ტორენტები დარჩეს; გაასუფთავეთ, რომ ყველა კვლავ გამოჩნდეს.

| ველი | ტიპი | მნიშვნელობა |
|---|---|---|
| `name` | ტექსტი | ტორენტის სახელი |
| `label` | ტექსტი | იარლიყის სახელი |
| `status` | ტექსტი | `downloading`, `seeding`, `uploading`, `paused`, `queued`, `error` |
| `progress` | რიცხვი | დასრულების პროცენტი |
| `size` | ზომა | სასურველი ზომა: `b` (ნაგულისხმევი), `kb`, `mb`, `gb` |
| `dl`, `ul` | სიჩქარე | ბაიტი წამში (ნაგულისხმევი), `kbps`, `mbps`, `gbps` |

ოპერატორები: `=`, `<`, `<=`, `>`, `>=` და `~` (შეიცავს, რეგისტრის
გარეშე), ერთდება `and`-ით და `or`-ით. ტექსტი ორმაგ ბრჭყალებში იწერება,
ერთეულები კი პატარა ასოებით.

```
name ~ "ubuntu"
size > 1gb and status = "downloading"
progress >= 90 or label = "Linux"
dl > 500kbps
```


## ტორენტების შექმნა

**ფაილი > Create torrent**:

![ტორენტის შექმნა](images/en-US/create-torrent.png)

- აირჩიეთ ფაილი ან საქაღალდე.
- **Mode**: v1, v2 ან ჰიბრიდი v1 + v2. ჰიბრიდი ყველა კლიენტთან მუშაობს
  და ნაგულისხმევია.
- **Comment** და **Creator** არასავალდებულოა.
- **Private**: პირები მხოლოდ ტრეკერებიდან მოდის, არა DHT-დან, PeX-დან ან
  ლოკალური ძიებიდან.
- **Add to session**: ახალი ტორენტის გავრცელების მაშინვე დაწყება.
- **Trackers (one per line)**: ყოველი ტრეკერი თავის დონეზე ხვდება;
  დონეები რიგრიგობით მოწმდება.
- **URL seeds (one per line)**: იგივე მონაცემების მქონე ვებსერვერები.
  საქაღალდისთვის მისამართი უნდა მიუთითებდეს საქაღალდეზე, რომელიც მას
  შეიცავს.


## პარამეტრები

**ხედი > პარამეტრები**. **Restore defaults** ყველა
პარამეტრს აბრუნებს. ზოგიერთ ცვლილებას (ენა, თემა, პორტები) გადატვირთვა
სჭირდება; პროგრამა თავად შემოგთავაზებთ.

### საერთო

![ზოგადი](images/en-US/preferences-general.png)

- **ენა** და **Theme** (სისტემური ან ღია; მუქი თემა Windows-ის
  პარამეტრს მიჰყვება).
- **Skip 'Add torrent' dialog**, **RePicoTorrent-ის ჩართვა Windows-სთან ერთად**, ფანჯრის
  **დაწყების პოზიცია**.
- **Show RePicoTorrent in notification area** და ფანჯრის ჩაკეცვისას ან
  დახურვისას იქ დამალვა.

### ჩამოტვირთვები

![ჩამოტვირთვები](images/en-US/preferences-downloads.png)

- **შენახვის ბილიკი**, **Move completed downloads** სხვა საქაღალდეში.
- **Pause when disk space is low**.
- **ზღვრები**: ჩამოტვირთვისა და ატვირთვის ლიმიტები KB/s-ში, რამდენი
  ტორენტი შეიძლება იყოს აქტიური ერთდროულად და კავშირების საერთო რაოდენობა.

### Labels

![იარლიყები](images/en-US/preferences-labels.png)

იხილეთ [იარლიყები](#იარლიყები).

### კავშირი

![კავშირი](images/en-US/preferences-connection.png)

- **სასმენი ინტერფეისი**: შემომავალი კავშირების მისამართები და პორტები.
  `0.0.0.0` და `[::]` ყველა IPv4 და IPv6 მისამართს ნიშნავს.
- **Encryption**: შემომავალი ან გამავალი კავშირების დაშიფვრის მოთხოვნა.
- **Privacy**: DHT, პირების ლოკალური ძიება (LSD), პირების გაცვლა (PeX),

## გადმოსვლა PicoTorrent-იდან ან qBittorrent-იდან

  ემატება ტორენტები და მათი იარლიყები; ფაილი მხოლოდ იკითხება. ყველაფრის,
  მათ შორის პარამეტრების გადმოსატანად, პირველ გაშვებამდე დააკოპირეთ
  `PicoTorrent.sqlite` `RePicoTorrent.exe`-ის გვერდით: მას
  `RePicoTorrent.sqlite` დაერქმევა.
- **ფაილი > Import from qBittorrent**: აირჩიეთ qBittorrent-ის
  `BT_backup` საქაღალდე (`%LOCALAPPDATA%\qBittorrent\BT_backup`). ინახება
  პროგრესი, ტრეკერები, მრიცხველები, საქაღალდეები და კომენტარები.

## ფაილები და ბრძანების სტრიქონი

`RePicoTorrent.exe`-ის გვერდით:

- `RePicoTorrent.sqlite`: პარამეტრები, ტორენტები და მათი გაგრძელების მონაცემები;
- `coredb.sqlite`: თარგმანები (პროგრამის ნაწილი);
- `logs`: ჟურნალის ფაილები;
- `Crashpad`: ავარიის დამპები, არასდროს იგზავნება;
- `dbip-country-lite.mmdb`: ქვეყნების ბაზა.

ბრძანების სტრიქონი:

```
RePicoTorrent.exe [--silent] [--save-path=<folder>] [file.torrent | magnet:?xt=...]...
```

`--silent` მითითებულ ტორენტებს დამატების ფანჯრის გარეშე ამატებს,
`--save-path` კი განსაზღვრავს, სად შეინახოს ისინი.
