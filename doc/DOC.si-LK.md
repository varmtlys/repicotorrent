## ගොනු සහ විධාන රේඛාව

`RePicoTorrent.exe` අසල:

- `RePicoTorrent.sqlite`: සැකසුම්, ටොරන්ට් සහ ඒවා නැවත ආරම්භ කිරීමේ දත්ත;
- `coredb.sqlite`: පරිවර්තන (වැඩසටහනේ කොටසක්);
- `logs`: ලොග් ගොනු;
- `Crashpad`: බිඳවැටීම් ඩම්ප්, කිසිවිටෙක උඩුගත නොවේ;
- `dbip-country-lite.mmdb`: රටවල දත්ත සමුදාය.

විධාන රේඛාව:

```
RePicoTorrent.exe [--silent] [--save-path=<folder>] [file.torrent | magnet:?xt=...]...
```

`--silent` ලබා දුන් ටොරන්ට් එක් කිරීමේ කවුළුවකින් තොරව එක් කරයි,
`--save-path` ඒවා සුරකින්නේ කොතැනද යන්න නියම කරයි.
